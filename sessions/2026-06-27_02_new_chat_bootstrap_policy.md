# 2026-06-27 새 채팅 초기화 지침 보강

## 배경

사용자가 Codex 새 채팅에서 작업을 시작할 때 프로젝트 맥락을 먼저 복원하도록 지침 보강을 요청했다. 특히 이 repo의 연구 테마와 최근 작업 이력을 확인한 뒤 작업에 들어가는 절차가 필요했다.

## 변경 내용

- root `AGENTS.md`에 새 채팅 초기화 규칙을 추가했다.
- 대화 이력이 비어 있는 새 Codex 채팅의 첫 의미 있는 작업에서만 적용하도록 제한했다.
- 연구 테마가 `CG + AI research on wind-driven deformable 3D Gaussian Splatting`임을 확인하도록 명시했다.
- 최근 3일의 session 기록을 root, `code`, `ideas`, `experiments` session 폴더에서 날짜와 번호 순서대로 확인하도록 명시했다.
- 최근 3일 기록이 없거나 맥락이 부족하면 가장 최근 날짜의 기록을 추가 확인하도록 했다.

## 비고

진행 중인 대화 중간에는 이 초기화 절차를 반복하지 않는다.
